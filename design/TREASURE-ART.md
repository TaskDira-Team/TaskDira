# Treasure shop artwork

The shop uses the built-in image-generation tool, with no external account connection.
Final asset: `Frontend/public/images/treasure-toys-atlas.png` (transparent PNG, 18 prizes, one shared texture).
`PrizeArt.jsx` selects a cell with CSS background positioning; unknown reward types use the existing Gift icon. Artwork never changes reward availability, cost, balance or XP.

## Generation prompt
Use case: stylized-concept. Asset type: one game sprite atlas texture for TaskDira, a playful children's household quest app. Create ONE landscape transparent sprite atlas, aspect ratio 3:2, with an exact 6-column by 3-row regular grid of 18 isolated miniature clay toy objects. Each cell is square, each toy centered exactly in its cell with generous 18% transparent padding on all sides. Consistent delightful premium tactile 3D clay toy rendering, rounded edges, teal coral lilac sunflower palette, soft studio lighting, front three-quarter view, clean shapes readable at 120 pixels. No backgrounds, no cell borders, no labels, no text, no shadows extending outside each cell, no extra objects or decorations between cells. Row 1 left to right: striped popcorn tub; three-scoop ice cream in bowl; paint palette and brush; small stack of colorful story books; purple game controller; triangular pizza slice. Row 2 left to right: coral camping tent; wicker picnic basket; teal music headphones; colorful diamond kite; three interlocking jigsaw puzzle pieces; cupcake with strawberry. Row 3 left to right: lilac telescope on tripod; two golden admission tickets; small teal bicycle; miniature carousel with coral canopy; blue over-ear headphones; little coral-and-teal toy space rocket. EXACTLY one toy group per cell. Uniform grid positioning is essential for CSS sprite display. Transparent alpha background.

## Final edit prompt
Edit this ONE game sprite atlas. Keep all 18 clay objects exactly as they are and keep the 6-column 3-row ordering. REMOVE all the colored haze, dark and brown backgrounds and shadows between the objects. Background must be absolutely transparent alpha, including all gaps and inside bicycle and telescope legs. Recompose as exactly 1536 pixels wide by 768 pixels tall (2:1 aspect ratio): six columns of 256px and three rows of 256px square cells. Center each object in its own square cell. Shrink each toy to fit inside the central 180x180 pixels of its cell with at least 38px transparent padding on all sides. No objects crossing cell boundaries, no colored glows, no background of any kind. Preserve lovely clay materials and colors, objects only.
